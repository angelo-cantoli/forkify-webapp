# Forkify 🍴

To take a look at the project go to this website: 'https://forkify-angelo.netlify.app'

A modern, vanilla JavaScript web application that allows users to search for over 1,000,000 recipes, view detailed ingredients, adjust serving sizes, bookmark their favorites, and upload custom recipes.

## ✨ Features

- **Search Functionality:** Search for a wide variety of recipes.
- **Pagination:** Easy navigation through search results.
- **Recipe Details:** View cooking time, servings, and a detailed list of ingredients.
- **Dynamic Servings:** Adjust the number of servings and instantly recalculate ingredient quantities.
- **Bookmarks:** Save your favorite recipes. Bookmarks are stored in your browser's local storage so they remain available even after reloading the page.
- **Add Custom Recipes:** Upload your own custom recipes to the application.

## 🛠️ Built With

- Vanilla JavaScript (ES6+)
- MVC (Model-View-Controller) Architecture
- [Parcel](https://parceljs.org/) - Web application bundler
- [Sass (SCSS)](https://sass-lang.com/) - CSS Extension language
- HTML5 / CSS3

## 🚀 Getting Started

If you want to run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone <your-github-repo-url>
   ```
2. Navigate to the project folder:
   ```bash
   cd forkify-webapp
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open your browser and go to `http://localhost:1234`.

## 📦 Building for Production

To build the application for production, run:

```bash
npm run build
```
This will create a `dist` folder with the optimized files ready to be deployed.
